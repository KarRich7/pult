# Пульт управления Philips 46PFL8606H/12 для iPhone (Expo / React Native)

Премиальное мобильное приложение-пульт для телевизора **PHILIPS 46PFL8606H/12** (серия 8000 Smart LED TV с подсветкой **Ambilight Spectra 2** и процессором Perfect Pixel HD).

Приложение работает по официальному сетевому протоколу **Philips JointSpace API** через Wi-Fi.

---

## 📱 Быстрый запуск на iPhone через Expo Go

1. Установите приложение **Expo Go** из App Store на ваш iPhone.
2. Убедитесь, что ваш компьютер и iPhone подключены к **одной и той же Wi-Fi сети**.
3. В терминале в папке проекта запустите сервер:
   ```bash
   npx expo start
   ```
4. Наведите камеру iPhone на появившийся в терминале QR-код (или откройте Expo Go и отсканируйте QR-код) — приложение мгновенно загрузится на телефон!

---

## ⚡ Активация JointSpace на телевизоре Philips 2011 года

Модель **46PFL8606H/12** относится к линейке 2011 года. На этих моделях сетевой интерфейс управления JointSpace включается секретным кодом (один раз):

1. Включите телевизор и переключитесь на любой эфирный/кабельный ТВ-канал.
2. На физическом пульте от телевизора быстро наберите цифры:
   ```
   5 6 4 6 8 7 7 2 2 3
   ```
   *(это слово **jointspace** по буквам на цифровой клавиатуре)*.
3. На экране телевизора появится сообщение **«JointSpace enabled»**.
4. Готово! Теперь телевизор слушает команды по Wi-Fi на стандартном порту **1925**.

> 💡 **Подсказка:** В самом приложении во вкладке «Цифры» также есть кнопка автоматической отправки этого кода.

## 🔍 Подключение к телевизору в приложении

1. Откройте приложение на iPhone.
2. Нажмите на иконку шестеренки ⚙️ (в правом верхнем углу).
3. Введите IP адрес вашего телевизора (например, `192.168.1.55`) или нажмите кнопку **«Найти»** в секции автопоиска — приложение само просканирует домашнюю сеть и найдет телевизор Philips.
4. Нажмите **«Тест связи»** — приложение покажет время отклика (пинг в мс) и модель телевизора.
5. Нажмите **«Сохранить»** — настройки сохраняются автоматически в памяти телефона.

## 🎛 Возможности пульта

- **Тактильный отклик (Haptic Feedback):** Каждое нажатие кнопки сопровождается мягкой вибрацией, создавая ощущение настоящего физического пульта.
- **D-Pad Навигация:** Классический круговой блок стрелок с центральной кнопкой **OK**, а также **HOME** (Smart TV Net TV), **OPTIONS**, **BACK**, **INFO**.
- **Качалки громкости и каналов:** Удобные спаренные кнопки **VOL +/-**, **CH +/-**, кнопка **MUTE** с индикатором состояния и **SOURCE**.
- **Цветные клавиши (Красная, Зеленая, Желтая, Синяя):** Для телетекста и интерактивных меню.
- **Вкладка «Цифры»:** Блок 0–9 для прямого переключения каналов + быстрая активация JointSpace.
- **Вкладка «Медиа»:** Управление воспроизведением (Play, Pause, Fast Forward, Rewind, Stop).
- **Выбор источника (Source):** Быстрое переключение входов HDMI 1, HDMI 2, HDMI 3, Side HDMI, TV, Satellite, YPbPr, VGA.
- **Студия подсветки Ambilight Spectra 2:**
  - Включение / выключение Ambilight.
  - Режим динамического слежения за картинкой на экране (`internal`).
  - Режим Lounge Light / Статический цвет (`manual`) с палитрой теплых и неоновых оттенков.

## 📦 Сборка автономного файла IPA для iPhone

### Способ 1: Автоматическая сборка в GitHub Actions (Рекомендуется)

В репозитории настроен автоматический CI/CD workflow (`.github/workflows/build-ios.yml`), который собирает `.ipa` на серверах Apple Silicon macOS в GitHub Actions:

1. Перейдите во вкладку **Actions** в репозитории: [https://github.com/KarRich7/pult/actions](https://github.com/KarRich7/pult/actions)
2. Выберите workflow **«Build iOS IPA»**.
3. Сборка запускается автоматически при каждом `push` в `main`, либо вручную по кнопке **«Run workflow»**.
4. По завершении сборки скачайте готовый архив **`PhilipsRemote-iOS-IPA`** из блока *Artifacts* (или со страницы *Releases*).

**Установка полученного `.ipa` на iPhone:**
- **TrollStore:** Устанавливается напрямую в 1 клик без ограничений.
- **AltStore / Sideloadly / Scarlet / ESign:** Откройте `.ipa` в программе на ПК или телефоне — программа автоматически подпишет приложение вашим бесплатным Apple ID и установит на iPhone.

### Способ 2: Облачная сборка через Expo EAS

1. Установите EAS CLI:
   ```bash
   npm install -g eas-cli
   ```
2. Авторизуйтесь:
   ```bash
   eas login
   ```
3. Запустите сборку:
   ```bash
   eas build --platform ios --profile preview
   ```
